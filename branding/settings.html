Download folders

Automatic by default

Download All automatically creates your date folder and a subfolder named after the open profile's Instagram handle. Descriptive filenames include the media owner, timestamp and media ID. No Organizer rule setup is needed in Automatic mode.

Files remain separate photos and videos inside the handle folder. No ZIP. The first new save is checked, then up to two files transfer together.

The addon shows one progress panel and restores the browser download UI when the batch finishes, stops, or its tab closes. Individual files still appear in download history.

While finding posts, the progress banner shows counts. During saving it shows completed files and a percentage. Use Stop to cancel the queue and its current file; completed files stay on disk.

Download All checks each saved file's actual name and profile folder. If another extension changes the destination, it stops after that file.

Default download folder

The date comes from the start of each file download. A batch crossing midnight can use two date folders.

Stories have two download buttons just below the top-right corner of the visible story: current story and all stories. Ctrl+Shift+D saves the current story. Individual posts and stories save directly in the date folder. Only a profile’s Download All creates a handle subfolder.

After updating the addon, reload the Instagram page itself before opening a highlight. The addon first uses media already loaded by that viewer; unavailable metadata lookups are a fallback.

Download cache

Media caching is enabled by default, up to 512 MB for 7 days. Retries reuse cached media. Files already saved in today's destination folder are skipped while the browser still confirms they exist.

Clearing this cache also resets saved-file tracking. It does not delete your downloaded photos or videos.

Optional Organizer mode setup

Add and enable this rule above your existing Instagram rule in RegExp Download Organizer. Leave its other matchers empty and keep Uniquify for name conflicts. The first capture creates the open profile's Instagram handle subfolder; the second sets the media filename.

This rule keeps the profile name and filename together. Your existing rule can continue to organize downloads from other Instagram tools.

About

Save photos, videos and carousel posts into a folder for each profile. Files go to your computer; this local build sends no analytics. Automatic mode uses your existing date-path layout without changing other extensions' rules.
